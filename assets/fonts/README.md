# Interface fonts

Inter is used for body copy, messages, controls and dense statistics. Oxanium is used for headings and short display labels. Numeric statistics use tabular numerals. Readable system fonts remain as fallbacks; the SKIRMISH ARENA SVG wordmark is unchanged.

Both files are original, unmodified variable TrueType fonts downloaded from the Google Fonts source repository on 2026-10-03. They are self-hosted: normal play makes no request to a third-party font service.
